This series follows the homelab from portable file sharing to a dedicated Ubuntu host, remote access, virtual machines and local AI. Start with the overview or choose the problem you need help with.

The **Prepared** date follows each document's original record-period date, rather than the date it was added to this website. **Recorded period** shows when the work took place; later follow-ups are identified separately. The parts stay in reading order even when their dates overlap.

Names and identifying details use consistent dummy values. Commands and output describe the setup at the time. Proposed fixes remain separate from completed tests, and unfinished work is marked clearly.
