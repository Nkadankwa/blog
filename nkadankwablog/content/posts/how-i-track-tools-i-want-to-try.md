I discover more tools than I have time to test. My way of keeping track depends on how interested I am and where I found the tool.

If it appears on social media, I usually save the post to a collection. A tool I find on the web goes into my bookmarks, and I may search for it once so it remains in my browser history. When I strongly want to try something, I place it in my notes.

## Different places represent different levels of interest

A social-media save is the lightest commitment. I can return later and decide whether the tool still seems relevant after the excitement of the post has passed. A bookmark is easier to organise around a category such as programming, privacy, or Windows utilities.

My notes contain the shorter list. I add why the tool caught my attention, the problem it might solve, and any requirement that could prevent me from using it. This stops the name from becoming another unexplained link.

## Saving a tool does not create a task

I dont use every software i save. Testing software takes time, can add background processes, and may scatter configuration across the laptop. I return to the list when a real project or frustration gives the tool a purpose.

Before installing, I check the official page or repository, supported systems, social media forums, and how removal works. That research can be enough to remove an item from the list.

This loose system matches the strength of my interest. Collections catch ideas, bookmarks make them findable, and notes finds tools that deserve my time. The list becomes useful when it helps me choose what to try next instead of reminding me of everything I have not tried.
