The Learning of Linux Commands and the Unexpected Pause

August 4, 2025◷ 1 min readUpdated Aug 4, 2025
On this page
  • Keeping the habit alive

Just as I was ready to spend more time with Linux, I had to lend my main computer to a friend. The hands-on homelab work paused, but I did not want the learning to pause with it.

So I made a smaller environment on my laptop: Docker Desktop with WSL2 and Ubuntu. It is not the final home lab, but it gives me somewhere safe to test ideas while the main machine is away.

Keeping the habit alive

I have been practising Linux commands daily with cmdchallenge.com, then slowing down to understand commands I do not recognise. Linux Journey, OverTheWire: Bandit, and the Docker documentation have been useful companions.

The biggest shift has been resisting the urge to copy commands without context. A working command is helpful; knowing why it works is better.

This temporary phase has made the project feel less like a pause and more like preparation. When the hardware returns, I will bring better habits—not just a longer to-do list.
